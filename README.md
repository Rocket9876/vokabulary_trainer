# Try it

The browser version: [itch.io](https://rocketrock.itch.io/vocabulary-trainer)

## Quick Start

Either use the vocabulary trainer in the [browser](https://rocketrock.itch.io/vocabulary-trainer) or download the release for Windows.

## Features

- Create Projects
- Manage your Projects
- Add your own Vocabulary, in two languages of your choice and with opptional grammar
- Manage your Vocabulary
- Customise the way the vokabulary trainer tests you on your Vocabulary
- a results page after every test where it shows you how much you got correct and how long it took you

## How to run locally

Required: Godot version 4.7 or above
```bash
git clone https://github.com/Rocket9876/vokabulary_trainer
```
Then just use the "import" feature in Godot, and there you have it!
